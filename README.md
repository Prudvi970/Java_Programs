# ☕ Java Programs

A comprehensive collection of Java programs designed to strengthen Core Java concepts, improve problem-solving skills, and prepare for coding interviews.

## 📌 About

This repository contains Java programs ranging from beginner to advanced level. It serves as a learning resource for understanding Java fundamentals, Object-Oriented Programming (OOP), Data Structures & Algorithms (DSA), and coding interview preparation.

## ▶️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/Prudvi970/Java_Programs.git
```

### Navigate to the Project

```bash
cd Java_Programs
```

### Compile

```bash
javac FileName.java
```

### Run

```bash
java FileName
```
